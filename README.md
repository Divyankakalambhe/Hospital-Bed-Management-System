# 🏥 Hospital Bed Management System

A real-time, responsive hospital bed management dashboard built with React (Vite), Node.js (Express), and PostgreSQL (Supabase).

## 🚀 Live Demo
* **Frontend (Website):** [https://smartbed-frontend.vercel.app](https://smartbed-frontend.vercel.app)

## 🛠️ Tech Stack
* **Frontend:** React, Tailwind CSS v4, Vite, React Router, Recharts
* **Backend:** Node.js, Express, Socket.io
* **Database:** PostgreSQL (Supabase)
* **Deployment:** Vercel

## 🌟 Features
* Real-time tracking of beds across multiple wards (ICU, General, Emergency, Maternity)
* Live dashboard with dynamic visual charts and recent alerts
* Comprehensive Patient Admissions, Doctor Registry, and Discharge tracking
* Instant Socket.io syncing across all connected devices
